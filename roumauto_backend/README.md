# RY Performance

Application web de location et gestion de véhicules performants et sportifs.

## Description

RY Performance est une plateforme permettant aux utilisateurs de consulter un catalogue de véhicules, effectuer des réservations et gérer les factures.

Le projet possède également un espace administrateur pour la gestion des véhicules, des clients et des remises.

---

## Fonctionnalités principales

### Côté utilisateur

- Consultation du catalogue des véhicules
- Recherche et navigation
- Réservation de véhicules
- Gestion des factures
- Application des remises

### Côté administrateur

- Gestion des véhicules
- Gestion des clients
- Gestion des réservations
- Gestion des remises
- Suivi des factures
